# Daily Standup Attendance

A simple, centralized attendance management tool for teams to record and track daily standup attendance.

## Overview

Daily Standup Attendance helps teams maintain attendance records in one place, making it easy to review team availability for any selected date.

## Features

- Track daily attendance for team members.
- Record attendance statuses: Present, Leave, Work From Home, and In Meeting.
- Add and manage team members.
- View attendance records by date.
- Export attendance reports as PDF or Excel.
- Access shared attendance records across devices.
- Clean, user-friendly interface.
